## 1. Плейсхолдеры — обязательно

Всё лежит в одном файле: [`src/data/site.ts`](src/data/site.ts).
Больше нигде эти значения не дублируются.

| Плейсхолдер | Где отображается | Что подставить |
|---|---|---|
| `{ИМЯ}` | шапка, H2 светлой секции, подвал, `<title>`, JSON-LD | имя и фамилия |
| `{ТЕЛЕФОН}` | шапка (моб.), форма, подвал | номер в читаемом виде |
| `phoneHref` | `href="tel:"` | тот же номер цифрами: `tel:+79178568489` |
| `{TG}` | кнопки Telegram | полная ссылка `https://t.me/...` |
| `{WA}` | кнопки WhatsApp | `https://wa.me/7917...` |
| `{КАНАЛ}` | пилюля-анонс, кнопка светлой секции | юзернейм канала без `@` |
| `{ИНН}` | нижняя строка подвала, оферта | ИНН или ОГРНИП |

Отдельно: `SITE.url` сейчас `https://example.ru` — заменить на боевой домен,
иначе canonical, OG и sitemap будут указывать не туда.

## 2. Решения, которые за тебя принимать не стал

**Метрика.** `SITE.metrikaId` = `null`. Пока так, вызовы целей молча не срабатывают.
Поставь номер счётчика — и заработают цели `lead_sent`, `tg_click`, `open_site`,
`tg_post`, `hero_tab`. Сам скрипт счётчика надо будет вставить в
[`src/app/layout.tsx`](src/app/layout.tsx) (я не стал: без номера вставлять нечего).

**Пилюля-анонс над H1** сейчас говорит «Новый разбор: лендинг для автосервиса».
Текст из спеки, но разбора такого у тебя может не быть — поправь на реальный
свежий пост в [`src/components/sections/Hero.tsx`](src/components/sections/Hero.tsx).

**Telegram-бот для заявок.** В [`public/api/lead.php`](public/api/lead.php) две константы:
`BOT_TOKEN` и `CHAT_ID`. Токен получить у `@BotFather`, свой chat id — у `@userinfobot`.
Токен живёт только в этом файле на сервере, в бандл фронтенда не попадает.
После заливки проверить форму с чужого телефона — это пункт чеклиста.

**Кейсы работ.** У всех проектов `caseUrl: null`, поэтому основной кнопкой в
витрине стоит «Открыть сайт». Появятся нишевые страницы или разборы — проставь
`caseUrl`, и кнопка сама станет «Разбор проекта», а «Открыть сайт» уедет в
мелкую текстовую ссылку. Код при этом не трогается.

**Посты в канале.** У всех `tgPost: null` — кнопка «Пост в Telegram» не рендерится
вообще (не серая, не «скоро»). Появятся посты — проставь ссылки.

**Нишевые страницы.** В [`src/data/niches.ts`](src/data/niches.ts) у всех ниш
`href: null`, поэтому бегущая строка и колонка в подвале — текст, а не битые ссылки.
Появятся страницы — проставь `href`, ссылки включатся сами.

## 5. Деплой

```bash
npm run build
```

Всё, что нужно выложить, лежит в `out/`. Внутри уже есть `.htaccess`
(gzip/brotli, кэш, 404) и `api/lead.php`. Заливать содержимое `out/` в корень
хостинга целиком.

После заливки проверить, что открывается `/policy/` и `/oferta/` — это проверка
`trailingSlash`, без него внутренние страницы на Apache отдают 404.
