# ЧАСТЬ 0. ЧТО ЭТО ЗА СТИЛЬ

У всех пяти референсов один язык. Это **тёмная продуктовая страница инди-Mac-приложения** — школа, которая сложилась в 2025–26 вокруг Raycast, Arc, Linear и десятков одиночных разработчиков. Её ещё называют dark glass / liquid glass product page.

Разбор по деталям, каждая — руководство к действию:

**1. Холст тёмный, но не чёрный.** `#0A0A0C`–`#121212`. Чистый `#000` встречается только внутри мокапов. Под ключевыми объектами — радиальные свечения фирменного цвета, очень широкие и слабые.

**2. Стекло.** Главная поверхность — полупрозрачная панель: заливка `rgba(255,255,255,.04)`, `backdrop-filter: blur(24px)`, граница `1px` в `rgba(255,255,255,.08)`, внутренний хайлайт сверху `inset 0 1px 0 rgba(255,255,255,.10)` и мягкая широкая тень вниз. Именно четыре слоя вместе дают «дорого». Три из четырёх — уже обычный тёмный див.

**3. Крупные радиусы.** 20–32px у панелей, 999px у всего, что кликается в один клик: кнопки, бейджи, шапка, теги.

**4. Продукт — единственный герой.** У Droppy на первом экране интерактивный макет notch, у Maccess — айфон с веером скриншотов, у Hejour — окно приложения. Абстракций нет ни у кого. Каждая секция показывает конкретный экран продукта, а не метафору.

**5. Плавающая шапка-пилюля.** Не прибитая к краям полоса, а стеклянная капсула в 12–16px от верха, по центру. На скролле слегка сужается и темнеет.

**6. Пилюля-анонс над заголовком.** «Updated on July 6» у Droppy, «New — Hejour is now on iPhone» у Hejour. Всегда кликабельна, всегда ведёт на свежее.

**7. В заголовке одно слово выделено.** Hejour делает это в каждом H2: *Notes that live in your **days***, *Keep your **days***, *7 apps. One **home***. Слово набрано курсивом другого шрифта. Это самый дешёвый по усилиям и самый заметный приём во всей подборке.

**8. Строчные eyebrow-подписи.** Над секцией мелкая строчная надпись: `how it works`, `testimonials`, `Privacy`, `Simple pricing`. Без капса, серым, 12–13px.

**9. Бенто.** Неровная сетка ячеек разной высоты и ширины, в каждой — своя визуалка, а не иконка. Ровных 3×2 из одинаковых карточек нет ни на одном из пяти сайтов.

**10. Липкие секции с видео.** Слева текст в три подпункта, справа зацикленное видео 5–8 секунд. Скроллишь — текст меняется, видео меняется, картинка стоит на месте. У Hejour так сделаны все четыре главные фичи.

**11. Бегущая строка.** Флаги стран у Hejour, ряд фич у Droppy, логотипы у TinyFolder. Бесконечный marquee в две строки навстречу друг другу.

**12. Микрофакты строкой под кнопкой.** `One-time purchase · Works on every display · macOS 14+`. Снимает возражения до того, как человек их сформулировал.

**13. Сравнительная таблица с альтернативой.** TinyFolder честно спрашивает «Can’t macOS already do this?» и отвечает таблицей. Приём сильный: сам называешь возражение — сам его закрываешь.

**14. Пружинное движение.** Появление снизу с расфокусом (`opacity + translateY + blur`), параллакс от курсора на макетах, свечение по краю при наведении. Всё на пружине, не на линейной кривой.

**15. Светлая секция-контрапункт.** У Hejour посреди тёмной страницы стоит пара «Looks right by day / Feels right at night». Одна светлая секция на тёмном сайте работает как удар.

**16. Цена одной крупной цифрой.** `$9.99`, `$19`, `$32` — и рядом словом «once». Никаких «от», никаких «рассчитаем индивидуально».

**17. Подпись автора в подвале.** «Built with 💙 by Jordy Spruit» с аватаркой. Для сайта-портфолио это вообще не украшение, а суть.

## Как это ложится на портфолио

У всех пяти сайтов герой — продукт. У меня продукт — сами сайты. Значит вся страница строится вокруг чужих экранов, и все стеклянные панели существуют ради того, чтобы держать скриншот.

**Сигнатурный элемент — живое окно.** На первом экране стоит макет окна браузера с работающей адресной строкой. Под ним — ряд табов с названиями работ. Клик по табу меняет адрес в строке и сайт внутри окна. Это единственная вещь на странице, которую можно потрогать, и она же — прямое доказательство: вот сайты, вот они листаются.

# ЧАСТЬ 1. ТЕХНИКА

**Стек:** Next.js 15 (App Router) + Tailwind v4 + shadcn/ui + framer-motion. Компоненты Magic UI и Aceternity UI — копипастой в `src/components/ui/`, не как зависимость.

Почему не Astro: все три библиотеки, которые ты назвал, написаны под Next + Tailwind, их код копируется из доков и работает без переделки. На Astro каждый компонент придётся оборачивать в остров и чинить импорты. Разница в чистой производительности здесь меньше, чем разница в скорости сборки.

**Хостинг остаётся прежний, поэтому вывод статический:**

```js
// next.config.mjs
output: 'export',
trailingSlash: true,        // /policy/ должен открываться как папка на Apache
images: { unoptimized: true }
```

`trailingSlash: true` обязателен — без него на шаред-хостинге внутренние страницы отдадут 404. `next/image` в статическом экспорте не оптимизирует, поэтому все картинки готовятся заранее в WebP.

**Структура:**

```
src/
  app/
    layout.tsx
    page.tsx
    policy/page.tsx           политика ПДн (152-ФЗ)
    oferta/page.tsx           договор-оферта
    sitemap.ts
    robots.ts
  components/
    sections/                 по секции на файл
    ui/                       shadcn + скопированные Magic UI / Aceternity
    mockups/                  BrowserFrame, PhoneFrame
  data/
    projects.ts
    niches.ts
    faq.ts
  styles/globals.css          токены + Tailwind v4 @theme
public/
  fonts/                      .woff2, кириллический сабсет отдельно
  works/                      скрины и видео работ
  noise.png                   зерно 128×128, tile
```

**Шрифты только локально.** Google Fonts из России отдаётся нестабильно. Скачать `.woff2`, положить в `/public/fonts`, подключить через `next/font/local` с `display: 'swap'`.

**Формы.** `POST` JSON на `/api/lead.php` — PHP-скрипт лежит рядом со статикой в `out/`, пересылает заявку в Telegram через Bot API. Токен только на сервере, данные не хранятся, в скрипте honeypot и проверка на пустоту. Состояния `idle → sending → success | error`, ответ показывается тостом (Sonner) и текстом на месте формы.

**Деплой:** `next build` → выгрузка `out/` по FTP. Рядом кладётся `.htaccess`: gzip/brotli, `Cache-Control: max-age=31536000, immutable` для `/_next/static/`, `ErrorDocument 404`.

**Мета:**

```
Title:       Разработка сайтов и лендингов в Нижнекамске — {ИМЯ}
Description: Делаю лендинги и многостраничные сайты для бизнеса в Нижнекамске
             и Татарстане. Дизайн, тексты, SEO-структура. От 7 дней, от 45 000 ₽.
             Работаю напрямую, без агентства.
```

JSON-LD: `Organization` + `LocalBusiness` (через `ServiceArea`, офиса нет), `FAQPage`, `BreadcrumbList`. Один `<h1>`. Заголовки секций — `<h2>`, названия работ и вопросы FAQ — `<h3>`.

Метрика: Яндекс.Метрика с вебвизором, цели на отправку формы, клик по Telegram, клик по «Открыть сайт», клик по табу в живом окне.

# ЧАСТЬ 2. ДИЗАЙН-СИСТЕМА

## Цвет

```css
--bg:         #0A0A0C;   /* холст */
--bg-2:       #101014;   /* секции-подложки */
--surface:    rgba(255,255,255,0.045);
--surface-2:  rgba(255,255,255,0.075);
--hairline:   rgba(255,255,255,0.09);
--hairline-2: rgba(255,255,255,0.16);   /* граница при наведении */
--text:       #F6F5F3;
--text-2:     #A3A19C;
--text-3:     #6C6A65;
--accent:     #FF4D2E;   /* действие и одно слово в заголовке */
--accent-2:   #FFA23A;   /* только как вторая точка градиента */
--paper:      #F4F2ED;   /* светлая секция «кто это делает» */
--ink:        #14130F;   /* текст на светлой секции */
```

Свечение — один рецепт, меняется только позиция:

```css
--glow: radial-gradient(680px 420px at var(--gx,50%) var(--gy,0%),
        rgba(255,77,46,.16), transparent 70%);
```

**Не больше двух источников свечения на экран.** Три и больше — сразу видно генеративную страницу.

Зерно: `noise.png` поверх фона, `opacity: .035`, `mix-blend-mode: overlay`, `pointer-events: none`. Слабее, чем кажется нужным.

## Стекло

Один класс, от него всё остальное:

```css
.glass {
  background: var(--surface);
  backdrop-filter: blur(24px) saturate(140%);
  border: 1px solid var(--hairline);
  border-radius: 24px;
  box-shadow:
    inset 0 1px 0 rgba(255,255,255,.10),
    0 24px 60px -24px rgba(0,0,0,.85);
}
```

При наведении меняется только граница на `--hairline-2` и заливка на `--surface-2`. Никаких `scale`, никаких подпрыгиваний.

## Радиусы и размеры

```
--r-sm: 12px     теги, инпуты
--r-md: 20px     ячейки бенто, строки таблицы
--r-lg: 28px     панели, тарифы
--r-xl: 40px     макеты, крупные визуальные блоки
--r-pill: 999px  кнопки, бейджи, шапка

Кнопка       44px высота, паддинг 0 22px, радиус pill
Инпут        48px высота, паддинг 0 16px, радиус 12px, шрифт 16px
Фокус        outline: 2px solid var(--accent); outline-offset: 3px
Тап на моб.  минимум 44×44px
```

**Инпут ровно 16px** — при меньшем iOS зумит страницу на фокусе.

## Типографика

Три роли, три шрифта. У каждого своя работа, декоративных нет.

| Роль | Шрифт | Где |
|---|---|---|
| Дисплей и текст | **Onest** (вариативный, кириллица родная) | заголовки, абзацы, кнопки |
| Акцентное слово | **Playfair Display Italic** | ровно одно слово в каждом заголовке |
| Служебное и цифры | **JetBrains Mono** | адресная строка, цены, счётчики, eyebrow, метрики |

Моноширинный здесь не украшение: сайт про разработку, и цифры в моно выравниваются в колонку сами.

```
H1          clamp(2.9rem, 6.4vw, 6.5rem)   вес 600  line-height 0.94  tracking -0.045em
H2          clamp(2.1rem, 4.2vw, 3.75rem)  вес 600  line-height 1.02  tracking -0.035em
H3          1.5rem                          вес 600  line-height 1.2
Lead        1.3rem                          вес 400  line-height 1.5   --text-2
Body        1.0625rem                       вес 400  line-height 1.65  --text-2
Eyebrow     0.8125rem  mono  строчными, tracking 0.02em, --text-3
Micro       0.75rem    mono  --text-3
```

**Акцентное слово — один способ на весь сайт.** Либо курсивный сериф, либо заливка градиентом `--accent → --accent-2`. Выбрать одно и не смешивать. Если сериф на тёмном покажется чужим — берём градиент, но тогда серифа нет нигде.

Текстовая колонка не шире **64 символов**. Заголовки — никогда капсом.

## Отступы

Шаг 4px. Вертикальный паддинг секций `clamp(96px, 12vh, 176px)`. Контейнер текста 1180px, контейнер широких визуалов 1440px, поля `clamp(20px, 5vw, 56px)`.

Разделительных линий между секциями нет — разделяет воздух, смена подложки и свечение.

## Движение

```
--dur-fast: 160ms
--dur:      280ms
--dur-slow: 600ms
--ease:     cubic-bezier(0.22, 1, 0.36, 1)

spring:     { type: 'spring', stiffness: 220, damping: 30, mass: 0.8 }
```

Появление секции: `opacity 0→1`, `translateY 24→0`, `filter: blur(8px)→0`, стагger 60 мс между дочерними, `IntersectionObserver` на 20%, один раз.

Параллакс от курсора — только на макетах, максимум ±8px по обеим осям, на пружине.

`prefers-reduced-motion: reduce` отключает всё, кроме смены цвета. `navigator.connection.saveData` отключает фоновые эффекты.

## Восемь запретов

Это антислоп-список. Он заменяет три запрета из первой версии — там боролись с шаблонностью, здесь боремся с «сгенерированностью».

1. **Ни одного эмодзи.** Иконки — только Lucide, обводка 1.5, размер 20. Один набор, один вес.
2. **Ни одной абстрактной 3D-фигуры, блоба или «нейросетевой» иллюстрации.** Внутри стеклянных панелей живут только реальные скриншоты, видео и интерфейсы.
3. **Не больше двух свечений на экран.**
4. **Ни одной ровной сетки из одинаковых карточек.** Бенто асимметричный: ячейки разной высоты, разной ширины, с разным содержимым.
5. **Ни одного заголовка со словами «Мы», «Наши», «Почему выбирают».**
6. **Не больше трёх «эффектных» компонентов из Aceternity / Magic UI на всю страницу.** Каждый следующий обесценивает предыдущий.
7. **Ни одной анимации, которая показывает саму себя.** Движение существует, чтобы показать работу.
8. **Ни одной придуманной цифры.** Нет «300+ проектов», нет счётчика довольных клиентов. Цифры только те, которые правда: срок, цена, срок правок.

## Шапка

Стеклянная капсула по центру, 16px от верха, `position: sticky`, ширина по контенту. Слева монограмма и имя, дальше `Работы · Ниши · Цены · Вопросы`, справа кнопка `Обсудить проект` заливкой `--accent`.

На скролле после 80px: паддинг уменьшается на 4px, `--surface` темнеет до `rgba(10,10,12,.72)`, тень усиливается. Плавно, 200 мс.

Мобильный: монограмма слева, телефон и Telegram иконками справа, пунктов меню нет.

## ЭКРАН 1

Секция `min-height: 100svh`, свечение сверху по центру. Всё по центру, окно — под текстом.

**Пилюля-анонс** (кликабельна, ведёт в Telegram-канал):
> Новый разбор: лендинг для автосервиса →

**H1** (акцентное слово выделено):
> Я делаю сайты для бизнеса в Нижнекамске. Вот **все**, которые я сделал.

Второе предложение — заявление о полноте. Так говорит только тот, кому нечего прятать, и работает даже с тремя работами.

**Подзаголовок:**
> Ни одного шаблона с автозаменой города. Каждый собран под конкретный бизнес: своя структура, свои тексты, своя ниша.

**Кнопки:** `Обсудить проект` (заливка `--accent`, pill) и `Смотреть работы` (стеклянная, pill).

**Микрофакты строкой** (mono, `--text-3`, разделены точками):
> от 45 000 ₽ · 7–10 дней · предоплата 50% · не подошёл прототип — возвращаю полностью

Цена стоит на первом экране. Это единственное место, где коммерческий блок должен опережать доказательства.

### Живое окно — сигнатурный блок

Макет окна браузера на всю ширину контейнера, радиус `--r-xl`, `.glass` c усиленной тенью, снизу подрезан краем экрана. Внутри:

- Хром окна: три точки, адресная строка в JetBrains Mono с реальным доменом работы, кнопка «Открыть ↗»
- Тело: зацикленное видео скролла сайта, `muted playsinline`, 6–8 секунд
- Под окном ряд табов-пилюль: `Автосервис` · `Стоматология` · `Спортпит` · `УЗИ и чек-апы`

Клик по табу: адрес в строке перебирается посимвольно за 220 мс, тело окна меняется кроссфейдом 260 мс, активный таб получает границу `--accent`. Первый таб активен по умолчанию, автопереключения нет — переключает только человек.

Параллакс от курсора на всём окне, ±8px, пружина. На мобильном окно уменьшается, табы уезжают в горизонтальный скролл, параллакс выключается.

## ЛИПКИЕ ФИЧИ

Три блока подряд, по схеме Hejour: слева текст в трёх подпунктах, справа зацикленное видео в стеклянной рамке, картинка `sticky` внутри секции.

> - **Проверяю на реальном телефоне** — не в эмуляторе, а на своём и на чужом.

> ## Заявка приходит в Telegram. Через **восемь секунд**, а не завтра.

> - **Ничего не хранится на сайте** — заявка уходит в бота и всё, базы для утечки просто нет.

# ЧАСТЬ 4. ВИТРИНА РАБОТ (карусель)

Самый сложный блок. Делается последним, отдельно от всего остального.

Основа — исходный код 3D-карусели банковских карт (файл `carousel-reference.tsx`). Ниже — что в нём меняется.

## 4.1. Раскладка

Секция на всю ширину, высота `100svh` (минимум 640px), фон `--bg-2`, сверху и снизу — растворение в `--bg` градиентом на 80px. Свечение под центральной карточкой, слабое.

**Слева (~45%)** — стеклянная панель описания активного проекта, радиус `--r-lg`:

```
[eyebrow, mono]      медицина · нижнекамск        ← ссылка на нишевую страницу
[H3]                 Студия массажа «Название»
[описание]           2–3 строки: задача и решение
[метрика, mono]      Собран за 9 дней

[кнопка основная]    Разбор проекта →
[кнопка стеклянная]  Пост в Telegram
[текстовая ссылка]   Открыть сайт ↗

[счётчик, mono]      03 / 07
```

**Справа (~55%)** — вертикальная 3D-карусель.

Исходник называется «horizontal carousel», но по математике карточки движутся **по вертикали** (`translateY`, вращение вокруг оси X). Для правой колонки это идеально — не трогать.

## 4.2. Что меняется в карточке

| Было в исходнике | Стало |
|---|---|
| Пропорция 1.5925 | **Оставить.** Скрин десктопа 16:10 = 1.6, совпадает почти идеально |
| Видео на лицевой стороне | Короткое видео скролла сайта или статичный скрин |
| Металлический чип SVG | Убрать |
| Логотип JWT сверху справа | Убрать |
| Пересекающиеся круги снизу | Убрать |
| Обратная сторона: полоса, номер, CVV | Тот же скрин в блюре + название проекта и ниша |
| `CARD_DETAILS` | `PROJECTS`, модель в 4.6 |
| `CARD_VIDEOS` — чужие CloudFront-ссылки | Свои файлы на своём хостинге. Чужие не трогать — отвалятся, и это не наши ассеты |
| 5 карточек | Столько, сколько реальных работ. 5–9 оптимум. Меньше 4 — карусель не собирать |
| Скругление 16px | **24px**, как у остальных панелей. Плюс граница `1px` в `rgba(255,255,255,.12)` — на тёмном она рисует край карточки |

Толщину `thicknessLayers` и объём **оставить** — это то, что делает эффект дорогим.

**Если работ меньше четырёх** — карусель не собирается вообще. Вместо неё две-три работы в ряд крупными стеклянными панелями с параллаксом от курсора, и живое окно с первого экрана берёт на себя всю нагрузку.

## 4.3. Управление

Автоплей как основной режим — плохо: человек не успевает прочитать описание и не чувствует контроля. **Скролл ведущий, автоплей запасной:**

1. **Покой:** медленный автоплёт, `progress += 0.0016`.
2. **Колесо мыши над блоком:** `wheel` меняет `progress`, автоплей встаёт, возобновляется через 3 секунды бездействия. Страница при этом **не блокируется** — никакого scroll-hijack.
3. **Драг и свайп:** `pointerdown/move/up`, движение по Y → прогресс.
4. **Клик по центральной карточке** → переход по `caseUrl`.
5. **Клик по боковой** → доводит её до центра, без перехода.
6. **Стрелки ↑↓ и Tab** — карточки должны быть фокусируемыми ссылками.

**Магнитная пауза** (`easedDiff` со степенью 4.2) — обязательно оставить. Именно она даёт ощущение, что карточка на секунду замирает ровно по центру. Без неё это просто крутилка.

## 4.4. Синхронизация с панелью

Активный индекс = `Math.round(progress)` по модулю числа проектов.

Смена описания: старое уходит `opacity 0 + translateY(-12px) + blur(6px)` за 180 мс, новое приходит за 220 мс с задержкой 120 мс. Кнопки приезжают последними, ещё +80 мс. Сначала «что», потом «куда идти». Счётчик меняется мгновенно.

**Тексты всех проектов лежат в DOM сразу.** Переключается только видимость через `opacity` и `aria-hidden`. Не подставлять текст из JS-массива в один контейнер — так поисковик увидит один проект из семи.

## 4.5. Три выхода с карточки

Они не равны по важности. Три одинаковые кнопки в ряд = человек не выберет ни одну.

| Куда | Приоритет | Оформление |
|---|---|---|
| `caseUrl` — разбор проекта | Основной | Заливная кнопка `--accent`, pill |
| `tgPost` — пост в канале | Вторичный | Стеклянная кнопка, pill |
| `liveUrl` — живой сайт | Третий | Мелкая текстовая ссылка со стрелкой |

**Клик по карточке = основной выход**, всегда, без промежуточного меню.

**Ниша в шапке панели — тоже ссылка** на нишевую страницу: главная раздаёт вес нишевым страницам не только через бегущую строку.

**Если `tgPost` или `liveUrl` равны `null` — кнопка не рендерится вообще.** Не серая, не задизейбленная, не «скоро».

Внешние ссылки: `target="_blank" rel="noopener"`, без `nofollow`. Оба клика — целями в Метрике.

## 4.6. Модель данных

```ts
export const PROJECTS = [
  {
    id:        'avtoservis-nk',
    title:     'Автосервис «Название»',
    niche:     'Автосервисы',
    nicheSlug: 'sayt-dlya-avtoservisa',
    caseUrl:   '/sayt-dlya-avtoservisa/#primer',
    city:      'Нижнекамск',
    desc:      'Две строки о задаче и решении.',
    metric:    'Собран за 9 дней',
    tgPost:    'https://t.me/{КАНАЛ}/47',   // null, если поста нет
    liveUrl:   'https://example.ru',        // null, если сайт снят
    poster:    '/works/avtoservis.webp',
    video:     '/works/avtoservis.webm',    // null — тогда только poster
    inHero:    true,                        // показывать табом в живом окне
    isDemo:    false
  },
]
```

`caseUrl` — одно поле независимо от того, куда ведёт. Пока в нише одна работа, кейс живёт якорем на нишевой странице; с трёх работ переезжает в `/cases/{id}/`. Меняется значение в данных, код не трогается.

`inHero: true` — работа попадает табом в живое окно на первом экране. Ставить максимум четырём.

`isDemo: true` — в углу карточки пилюля «демо-концепт», кнопка подписывается «Открыть демо ↗». Демо-шаблоны показывать наравне с клиентскими можно, выдавать за клиентские — нет.

## 4.7. Мобильная версия

Ниже 768px вертикальной 3D-каруселью пользоваться невозможно: параллакса нет, вертикальный свайп конфликтует со скроллом, семь видео убивают телефон.

- Карточки в ряд **по горизонтали**, свайп вбок, `scroll-snap-type: x mandatory`
- Глубина слабее: соседние `scale 0.88`, поворот убрать
- Параллакс от курсора отключён полностью
- Видео заменяются на `poster`, играет максимум одно центральное
- Панель описания переезжает под карусель, на всю ширину
- `thicknessLayers` с 5 слоёв до 3
- Тап по карточке ведёт по `caseUrl`, но не срабатывает, если палец сдвинулся больше 10px

# ЧАСТЬ 5. КОМПОНЕНТЫ — ЧТО ОТКУДА БЕРЁТСЯ

Библиотеки — источник кода, не источник решений. Каждый компонент ставится под конкретную задачу из части 3, ничего «на всякий случай».

**shadcn/ui** — база, ставится вся сразу:
`Button`, `Input`, `Textarea`, `Checkbox`, `Label`, `Badge`, `Table`, `Tooltip`, `Sonner`. Тема перекрашивается на токены из части 2 через `@theme` в `globals.css`. Компонент `Accordion` **не используется** — FAQ на нативных `<details>`.

**Magic UI** — копипастой, только эти:

| Компонент | Куда | Правки |
|---|---|---|
| `AnimatedShinyText` | пилюля-анонс над H1 | блик медленнее, 4s вместо 2s |
| `Marquee` | бегущая строка ниш | одна строка вместо двух, `mask-image` по краям |
| `BentoGrid` | секция «что входит» | сетка переписывается на асимметричную, дефолтная слишком ровная |
| `BorderBeam` | средний тариф | цвет луча из `--accent`, скорость вдвое медленнее |
| `Safari` (мокап браузера) | живое окно | хром перерисовывается: адресная строка в mono, кнопка «Открыть» |

**Aceternity UI** — только два:

| Компонент | Куда | Правки |
|---|---|---|
| `Spotlight` | свечение на первом экране | цвет из `--accent`, прозрачность вдвое ниже дефолта |
| `Glowing Effect` | ячейки бенто при наведении | только свечение по краю, вращающийся луч выключить |

Итого три «эффектных» компонента на страницу: `BorderBeam`, `Spotlight`, `Glowing Effect`. Лимит из части 2 выбран полностью, добавлять нечего.

**Не брать вообще:** `TextGenerateEffect` и любые эффекты набора текста (ломают LCP и индексацию), `BackgroundBeams`, `Meteors`, `Lamp`, `WavyBackground`, `Globe`, `Vortex` — всё это украшает само себя, а не работу. `InfiniteMovingCards` не нужен: отзывов пока нет, а поддельных не будет.

**framer-motion** подключается через `LazyMotion` + `domAnimation`, тяжёлые секции — `dynamic(() => import(...), { ssr: false })`.

# ЧАСТЬ 7. ПРОИЗВОДИТЕЛЬНОСТЬ

Стеклянные панели с `backdrop-filter` — самое дорогое, что есть в CSS. Их количество на экране ограничено.

- **Не больше 4 элементов с `backdrop-filter` одновременно в зоне видимости.** Остальные панели — сплошная заливка `rgba(255,255,255,.045)` без блюра, разница на глаз не читается
- `will-change: transform` только на видимых карточках карусели, снимается при уходе из вида
- Каждая липкая секция и карусель инициализируются через `IntersectionObserver`: до появления видео не грузятся, `requestAnimationFrame` не запускается, при уходе — `cancelAnimationFrame` и пауза
- Играют только центральное и два соседних видео, остальные `.pause()` и показывают `poster`
- `prefers-reduced-motion: reduce` → карусель превращается в обычный ряд превью, все видео заменяются постерами, бегущая строка останавливается
- Бюджет: LCP < 2.5s на 4G, CLS < 0.05, вес первого экрана < 900 КБ вместе со шрифтами
